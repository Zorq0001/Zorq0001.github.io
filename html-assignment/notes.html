HTML Tags I Learned

Here’s a list of some HTML tags I picked up in class and what they’re for:

<h1>
This one makes the main heading on a page.
<p>
You use this to write out a paragraph.
<img>
If you want to show an image, this tag does the trick.
<a>
This tag lets you addadd linkslinks to other pages or websites.
<ul>
You can make a bulleted list with this tag.
